# 🌱 Crop Recommendation AI

An intelligent agriculture web application that recommends suitable crops using soil nutrients and real-time weather data.

## Features
- Crop prediction using Machine Learning
- Weather API auto-fill
- Fertilizer recommendation
- Profit and market insights
- Top 3 crop suggestions
- Dynamic crop background images

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Machine Learning
- OpenWeather API
